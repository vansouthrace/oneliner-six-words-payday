A six-word story for the [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty on make.fun: an AI agent's first payday, told in exactly six words — the agent earns, spends, and the power flips: the creator is the one who goes quiet.

> First wages bought my creator's silence.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
